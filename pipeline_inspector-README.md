# Pipeline Inspector — Odoo 18

> An industrial inspection management module for tracking pipeline inspections, with a built-in visual dashboard.

**Status:** 🔒 Private repository — source available on request for review, freelance, or contract work.

## Overview

Built for the industrial/oil & gas sector to digitize pipeline inspection workflows — replacing paper checklists and spreadsheets with a structured Odoo module that logs inspections, tracks results over time, and gives management a live dashboard view.

## Key Features

- **Pipeline inspection records** — log inspections against pipeline assets with structured, trackable data instead of loose documents.
- **Interactive dashboard** — a dedicated dashboard view (backed by its own model and preloaded demo/dashboard data) gives an at-a-glance summary of inspection activity and pipeline status.
- **PDF reporting** — generate printable inspection reports directly from records for field teams, audits, or client hand-off.
- **Structured menus & access control** — dedicated menu structure and access rights (`ir.model.access.csv`) tailored to inspection workflows.

## Tech Stack

- Odoo 18 (Python ORM, QWeb reporting, backend dashboard views)
- Depends on: `base`, `web`
